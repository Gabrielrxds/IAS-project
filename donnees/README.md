# Données

Les données de l'hôpital ne sont pas versées dans le dépôt (voir `.gitignore`).

Déposer ici `donees_bloc_anonyme_pour_centrale_2026.xlsx` (14 649 interventions, 2019-2022), ou
indiquer son chemin par la variable d'environnement :

```bash
export BLOC_DONNEES=/chemin/vers/donees_bloc_anonyme_pour_centrale_2026.xlsx
```

L'étude tabou d'origine (`etudes_origine/tabou/`) accepte aussi l'option `--donnees chemin.xlsx`.
