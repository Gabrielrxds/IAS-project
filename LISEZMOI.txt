PROJET BLOC OPÉRATOIRE — RECUIT SIMULÉ
======================================

Tout est déjà dans ce dossier. Ne déplacez aucun fichier dans un sous-dossier.

1. Dézippez, puis dans VS Code : Fichier > Ouvrir le dossier... > choisissez CE dossier.

2. Une seule fois, dans le terminal de VS Code :
   python -m pip install pandas openpyxl matplotlib seaborn scikit-learn scipy notebook ipykernel nbformat

3. Ouvrez analyse_base_de_donnees.ipynb, choisissez votre Python en haut à droite, puis « Run All » (~10-15 min).
   -> crée base_preparee/ (base propre, dictionnaire, rapport de qualité, profils...)
   -> crée modeles/predicteur_sejour.joblib (prédiction de la durée d'hospitalisation)

4. Ouvrez rapport_recuit_grille.ipynb, puis « Run All ».
   - Première cellule de code : RAPIDE = True pour un test (~15-25 min),
     puis RAPIDE = False pour l'étude complète (~1 h à 1 h 30, ordinateur branché, sans mise en veille).
   -> résultats dans resultats_notebook/ et resultats_recuit/ (dont grille_A.xlsx et grille_B.xlsx)

5. Ctrl+S, puis « ... » > Exporter > HTML pour envoyer les rapports.

Contenu :
- donees_bloc_anonyme_pour_centrale_2026.xlsx : la base de l'hôpital
- modele.py : modèle du groupe (version allégée, mêmes formules ; remplaçable par la version complète)
- preparation_donnees.py : nettoyage et préparation de la base (durée de séjour calculée par les dates)
- urgences.py : classification des urgences (U1, U2, P2, P3, P4) d'après la FSSA, le NCEPOD et la SFAR/SOFCOT
- prediction_sejour.py : prédiction de la durée d'hospitalisation à la consultation (profil de lits par patient)
- donnees_reelles.py, fonctions_cout.py, recuit.py : recuit simulé au niveau des patients
- grille_vacations.py, recuit_grille.py : recuit simulé sur la grille de vacations
- etude_recuit.py, etude_grille.py, analyse.py : études et figures utilisées par les notebooks

En cas d'erreur « fichier manquant » : ajoutez une cellule avec
   import os; print(os.getcwd()); print(os.listdir())
et vérifiez que tous ces fichiers apparaissent.
